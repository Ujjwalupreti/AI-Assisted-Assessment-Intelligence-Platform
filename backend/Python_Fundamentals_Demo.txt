PYTHON FUNDAMENTALS – DEMO COURSE MATERIAL

1. Python Basics

Python is a high-level, interpreted programming language.
Python programs are generally easy to read because Python uses indentation
to define code blocks instead of curly braces.

Variables in Python do not require explicit type declarations.
A variable can refer to objects of different types during program execution.

Example:
x = 10
name = "Alice"

The print() function displays values on the console.

Example:
print("Hello")

2. Python Data Types

Common built-in Python data types include:
int, float, str, bool, list, tuple, set and dict.

An integer represents whole numbers.
A float represents numbers with decimal values.
A string represents a sequence of characters.
A Boolean represents True or False.

3. Conditional Statements

The if statement executes a block when a condition is true.

Example:

if age >= 18:
    print("Adult")

The elif statement allows additional conditions to be checked.
The else block executes when none of the preceding conditions are true.

4. Loops

Python provides for and while loops.

A for loop is commonly used to iterate over elements of a sequence.

Example:

for number in numbers:
    print(number)

A while loop continues execution while its condition remains true.

5. Functions

A function is a reusable block of code.

Functions are defined using the def keyword.

Example:

def add(a, b):
    return a + b

Parameters allow values to be passed into a function.
The return statement sends a value back to the caller.

6. Lists

A list is an ordered and mutable collection.

Example:

numbers = [10, 20, 30]

List elements can be accessed using indexes.
Python uses zero-based indexing, so the first element has index 0.

Lists can be modified using operations such as append(), insert()
and remove().

7. Dictionaries

A dictionary stores data as key-value pairs.

Example:

student = {
    "name": "Alice",
    "age": 20
}

Dictionary values can be accessed using their keys.

8. Exception Handling

Python uses try and except blocks to handle exceptions.

Example:

try:
    result = 10 / 0
except ZeroDivisionError:
    print("Cannot divide by zero")

Exception handling prevents certain runtime errors from terminating
the normal flow of a program.

9. Object-Oriented Programming

A class defines the structure and behavior of objects.

An object is an instance of a class.

The __init__ method is commonly used to initialize object attributes.

Inheritance allows a class to reuse or extend behavior from another class.

10. File Handling

Python can open files using the open() function.

Common file modes include:
r for reading
w for writing
a for appending

Files should generally be closed after use, or managed using the with statement.

11. Complexity and Algorithms

An algorithm is a sequence of steps used to solve a problem.

Linear search checks elements sequentially.
Binary search repeatedly divides a sorted search space into smaller parts.

Binary search has O(log n) time complexity in the typical case.
Linear search has O(n) time complexity.

12. Python Modules

A module is a Python file containing definitions and statements.
The import statement allows functionality from another module to be used.

Example:

import math

The math module provides mathematical functions.
